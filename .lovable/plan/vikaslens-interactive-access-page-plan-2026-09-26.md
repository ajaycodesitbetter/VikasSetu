# VikasLens interactive access-page plan

## Goal

Recreate the uploaded split-screen design as a polished, working VikasLens — Gwalior Edition access page. Preserve its recognizable composition while replacing the generic portal styling with the civic, editorial direction in the supplied brief.

## Build

- Replace the blank home page with a responsive 55/45 split-screen experience.
- Keep the left-side district-development scene, layered messaging, three restrained value blocks, trust signals, and quote closely aligned to the reference composition.
- Use VikasLens branding, “District development, made visible,” and the “Independent civic-tech prototype” label without government seals or official-looking emblems.
- Create a warm off-white, forest-green, charcoal, and sage visual system with multilingual-friendly typography and subtle motion.
- Build the right-side access form with Citizen and Planner demo modes, full name, mobile, OTP, optional email, state, district, information notice, Continue, guest access, Google, and DigiLocker actions.

## Working interactions

- Make every visible icon and control respond: language menu, login/create-account switch, role selector, field icons, OTP action, state and district selectors, primary/secondary actions, and provider buttons.
- Add sensible form validation, loading/confirmation feedback, disabled states, and a usable Planner demo state.
- Keep this version an interactive prototype: entered profile details remain in the current page session only and do not create real accounts or permanently save personal data.
- Use a clear guest-success state and realistic prototype feedback for Google and DigiLocker rather than implying completed external authentication.

## Five-language experience

- Support exactly English, हिंदी, मराठी, বাংলা, and தமிழ்.
- Translate all visible copy named in the brief, including the left-panel content, trust labels, form copy, controls, notices, and login/create-account modes.
- Keep the layout stable for longer translations and give Indian scripts appropriate line height and field height.

## Visual asset

- Use the uploaded image as the structural and visual reference, not as a flattened screenshot.
- Create a clean, realistic Gwalior-region development scene for the left panel so the interface remains selectable, accessible, and interactive.

## Quality and verification

- Add unique VikasLens page metadata and accessible labels, focus states, and keyboard behavior.
- Verify desktop and mobile layouts, all five languages, both roles, login/create-account switching, validation, guest flow, and every visible control in the live preview.

## Scope boundary

Real authentication, SMS delivery, Google/DigiLocker connections, and permanent profile storage are excluded from this prototype. They can be connected later without changing the visual design.
